# Excavatio — Ancient World Explorer

Two tools in one:

- **Excavation Map** — Real-time map of classical & ancient Greco-Roman excavations, powered by the [Pleiades](https://pleiades.stoa.org) gazetteer.
- **Text Identifier** — Paste a Greek or Latin passage (or upload an image of text) to identify the classical work, get a fact file with context, line numbers, and multiple translations/editions.

## Deployment

```bash
git push bld main
```

## Local dev

```bash
pip install -r requirements.txt
python app.py
```
